El programa se encuentra en Github por lo que para instalarlo es necesario bajarse el repositorio del proyecto en una carpeta que tenga permisos de lectura, escritura y ejecución.
Una vez descargado el proyecto se debe ejecutar el proceso “instalar_herramintas.bat” ubicado en la carpeta “analizador-calidad-software/src/analizador_calidad_software”. 

Para ejecutar el programa se debe lanzar el proceso “ejecutar_analisis.bat” ubicado en la carpeta “analizador-calidad-software/src/analizador_calidad_software” (Se puede crear un acceso directo en el escritorio para facilitar su ejecución).
